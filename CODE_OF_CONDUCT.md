# Code of conduct

JobBear follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique code and not people, and help newcomers.
Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through the contact on
[his GitHub profile](https://github.com/benjaminbelloeil). Reports are handled confidentially.
